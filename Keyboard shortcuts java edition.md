## Шаблоны для IntelliJ IDE

Просто вводи эти буквы и жми **Tab** (или **Enter**).

| Сокращение | Что развернется | Описание |
| --- | --- | --- |
| **`psvm`** | `public static void main(String[] args) {...}` | Главная точка входа в программу. |
| **`sout`** | `System.out.println();` | Самый классический вывод в консоль. |
| **`souf`** | `System.out.printf("");` | Вывод с форматированием. |
| **`soutm`** | `System.out.println("ClassName.methodName");` | Печатает имя текущего класса и метода (удобно для логов). |
| **`soutv`** | `System.out.println("var = " + var);` | Печатает имя переменной и её значение (IDEA сама предложит ближайшую). |

---

## 🔄 Циклы и итерации

Работа с массивами и коллекциями становится в разы приятнее:

* **`fori`**: Классический цикл со счетчиком `for (int i = 0; i < ; i++)`.
* **`iter`**: Цикл "foreach" для перебора коллекции или массива.
* **`itli`**: Итерация по `List` (по индексу).
* **`inn`**: Быстрая проверка на «не null» (`if (x != null) {...}`).

## 🛠 Магия суффиксов (Postfix Completion)

Это даже круче, чем обычные шаблоны. Ты пишешь переменную, ставишь точку и дописываешь команду.

1. **`.sout`**: Напиши `myVar.sout` → превратится в `System.out.println(myVar);`.
2. **`.var`**: Напиши `new ArrayList<String>().var` → IDEA сама создаст переменную нужного типа слева.
3. **`.if`**: `(a > b).if` → сразу обернет это условие в блок `if`.
4. **`.notnull`**: Быстрая проверка объекта.
5. **`.for`**: Сразу создает цикл по объекту, перед которым стоит точка.

## 💡 Как посмотреть всё или создать своё?

Если хочешь увидеть весь список или добавить свой прикол (например, чтобы по слову `hello` создавался весь твой стандартный код):

1. Зайди в **Settings** (Ctrl+Alt+S).
2. Перейди в **Editor** → **Live Templates**.
3. Там можно найти раздел **Java** и посмотреть, что еще есть, или нажать на **+**, чтобы создать свой шаблон.

> **Совет:** Попробуй в коде нажать **Ctrl + J**. Выскочит список всех доступных шаблонов прямо в том месте, где стоит курсор.
